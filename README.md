# LivGruha Interiors 🏛️✨

> **Complete Home Interiors — Handover in Just 21 Days**  
> Serving Telangana, Andhra Pradesh, and Karnataka.

---

## 🌟 Highlights & Features

- **21-Day Guaranteed Handover**: Systematic 7-step customer journey backed by automated factory fabrication.
- **Free 3D Design Consultation Studio**: High-conversion 3-step consultation wizard with floor plan upload & WhatsApp sync.
- **Interactive Scope Planner & Cost Estimator**: Room-by-room module selector with instant PDF specification downloads.
- **Before & After 50/50 Transformation Slider**: Touch-draggable split slider showcasing real turnkey transformations.
- **Brand Partners Integration**: Global hardware & material partnerships (Blum, Hettich, Saint-Gobain, Greenply, Merino, Asian Paints).
- **Admin Control & Real-Time Lead Attribution Portal**: Built-in dynamic CMS with Google Sheets webhook integration and full data export/import capabilities.
- **Mobile-First Responsive Design**: Optimized for smartphones, tablets, and desktops with 100% Lighthouse performance standards.

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production (Vercel / Netlify)
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/Atif2292/Livgruha.git
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `Livgruha` repository.
4. Framework Preset: **Vite**
5. Click **Deploy**!
